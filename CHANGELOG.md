# Changelog

Все заметные изменения проекта. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

## [1.0.2] — 2026-10-23

### Исправлено
- **Краш «Не удалось создать главное окно: QDockWidget.setFeatures(int)»**
  на PySide6 6.9+ (включая 6.12). Причина: перечисление `DockWidgetFeature`
  живёт в классе `QDockWidget`, а не в `Qt`; compat-слой не находил его и молча
  подставлял число, которое строгий PySide6 отбивал TypeError'ом.
- Та же профилактика для всех кнопочных флагов: `QDialogButtonBox(...)` и
  сравнения кодов результата диалогов теперь получают типизированные enum'ы,
  а не `int` (иначе следующий TypeError прилетел бы при открытии настроек).
- Compat-слой переписан: значения ищутся по цепочке владельцев, а при промахе
  КОНСТРУИРУЮТСЯ из enum-класса (`Enum(int)`), поэтому голое число больше не
  может просочиться в вызов Qt.
- Новая механическая проверка `app/ui/qt_pyi_check.py` + тест
  `tests/test_qt_compat_stubs.py`: сверяет каждое используемое перечисление
  с `.pyi`-стабами установленного PySide6 (41 член, включая
  `QDockWidget.DockWidgetFeature.*`) — без запуска Qt и без дисплея.
  Запуск: `python scripts/dev_check_qt_compat.py`.

## [1.0.1] — 2026-10-23

### Изменено
- **Поддержка Python 3.14 и новее.** Верхняя граница версии убрана: bootstrap
  принимает любой Python ≥ 3.10 (64-bit). Наличие wheel'ов всех зависимостей
  под cp314 проверено по PyPI (ctranslate2, numpy, av, onnxruntime, tokenizers,
  pywhispercpp имеют cp314-сборки; PySide6/shiboken6 — стабильный abi3;
  vosk/imageio-ffmpeg/faster-whisper — платформенно-независимые wheel'ы).
- При выборе интерпретатора теперь проверяется **битность**: 32-битный Python
  отклоняется сразу с понятным сообщением вместо необъяснимого провала pip.
- Если в системе несколько Python, предпочитаются самые обкатанные
  (3.12 → 3.13 → 3.11 → 3.10 → 3.14 → любой новее).
- Ошибка установки пакетов теперь содержит подсказку: поставить рядом
  Python 3.12/3.13 — программа подхватит его автоматически.

## [1.0.0] — 2026-10-23

### Добавлено
- Первый публичный релиз.
- **Bootstrap**: `main.py` сам создаёт `.venv`, ставит зависимости (uv, если
  доступен, иначе pip), проверяет их по «отпечатку» и перезапускает GUI без
  консоли (`pythonw.exe` на Windows). Все ошибки показываются в нативном окне
  и пишутся в `logs/bootstrap*.log`; консоль не закрывается мгновенно.
- **GUI на PySide6** (не Tkinter): тёмная тема, drag & drop, живой журнал,
  прогресс с оценкой остатка времени, отмена в любой момент.
- **Каталог из 17 моделей** трёх движков с указанием размера файла, потребления
  RAM/VRAM, поддерживаемых языков, оценок точности/скорости и рекомендации под
  detected hardware. Приоритет — русский язык.
- **Три движка**: faster-whisper (CTranslate2, batched + Silero VAD + int8),
  whisper.cpp (GGML, pywhispercpp), Vosk (Kaldi).
- **Своя модель по ссылке/пути**: HF-репозиторий (в т.ч. с подпапкой), прямая
  ссылка на файл, архив Vosk, локальная папка. Движок определяется автоматически.
- **Анти-галлюцинации**: чистка `[музыка]`, `[аплодисменты]`, «Спасибо за
  просмотр», субтитрных вставок, петель повторов и низкокачественных сегментов.
- **Экспорт**: `.txt`, `.txt` с таймкодами, `.srt`, `.vtt`, `.json` (сегменты и
  слова), `.md`; имя результата = имени оригинала (`лекция 1.mp4` → `лекция 1.txt`).
- **Скорость**: prefetch декодирования следующего файла, однократная загрузка
  модели на очередь, batched-декодинг, пайп ffmpeg → numpy без временных WAV,
  параллельная обработка нескольких файлов (опционально).
- **CLI**: `transcribe`, `list-models`, `doctor`, `version`.
- **Тесты**: 200+ проверок, включая GUI-смоки на стабе PySide6 и интеграционный
  тест полного пайплайна.

### Известные ограничения
- NVIDIA CUDA на Windows требует системных DLL cuBLAS/cuDNN 9 (см. README).
- VAD внутри whisper.cpp отключён: свежий whisper.cpp требует внешний файл
  модели Silero VAD, а без него молча возвращает ноль сегментов.
- Diarization (разделение по спикерам) не реализован — в бэклоге.
