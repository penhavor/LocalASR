# Changelog

Здесь отмечаются все значимые изменения LocalASR.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект использует [семантическое версионирование](https://semver.org/lang/ru/).

## [v1.1.0] — 2026-10-26

### Добавлено

- **Встроенная система обновлений.** При запуске программа (если есть интернет)
  тихо сравнивает установленную версию с последним релизом на GitHub; при
  обновлении скачиваются **только изменённые файлы** — побайтово сравниваются
  хэши каждого файла с деревом релиза (GitHub git trees API), а загружаются
  лишь добавленные/изменённые. Файлы, удалённые в новой версии, удаляются и
  локально. Пользовательские данные (models/, outputs/, logs/, settings/,
  окружения runtime/ и .venv/) не затрагиваются никогда. Без интернета
  автоматическая проверка просто молчит; после обновления предлагается
  перезапуск. Новый модуль: `app/core/updater.py`.
- **Пункт меню «Справка → Проверить обновления…»** — ручная проверка в любой
  момент. В ручном режиме результат сообщается всегда: «установлена последняя
  версия», «нет доступа к GitHub» (явное предупреждение) или предложение
  обновиться с показом версии, числа файлов и объёма скачивания.
- **Оценка масштаба обновления ДО установки**: предложение обновиться помечено
  как «Крупное обновление» (новая мажорная версия, изменённые зависимости или
  заменена половина файлов программы и больше) или «Небольшое обновление»,
  плюс строки «будет добавлено / изменено / удалено (объём)». Если обновление
  затрагивает зависимости (requirements/base.txt), показывается отдельное
  предупреждение ⚠, а перезапуск после установки идёт через launcher/main.py —
  bootstrap сам доустановит библиотеки.
- **Верификация ПОСЛЕ обновления**: каждый файл программы сверяется по
  git-blob-хэшу с деревом релиза. Успех — явное сообщение «обновление
  завершилось успешно: все N файлов совпадают с релизом»; неудача (обрыв
  интернета и т.п.) — сообщение со списком несовпавших файлов и предложением
  сразу повторить проверку, которая докачает только недостающее.
- **Режим ремонта**: если после прерванного обновления версия уже выглядит
  актуальной, а файлы релизу не соответствуют, повторная проверка (кнопка
  «Проверить обновления…» или «Повторить» в окне неудачи) сверяет установку с
  деревом релиза и предлагает восстановить только несовпадающие файлы —
  пользовательские данные по-прежнему не трогаются.
- **Выбор формата результата в главном окне** (выпадающий список в блоке
  «2 · Как распознавать и куда сохранять»): TXT (по умолчанию), SRT, VTT,
  JSON, Markdown. Ранее GUI всегда сохранял только .txt, а остальные форматы
  были доступны лишь через CLI. Галочка «Таймкоды в .txt» теперь активна
  только для формата TXT. Подсказка с примером имени файла учитывает выбранный
  формат и его расширение.
- Этот файл (`CHANGELOG.md`) — история версий проекта.
- Тесты системы обновлений: `tests/test_updater.py` (разбор версий, git-blob
  хэши, дифф-план, безопасность удалений, офлайн-режим, применение обновления
  без сети).

### Исправлено

- **Сброс настроек больше не оставляет интерфейс в старом языке.** Раньше,
  если язык интерфейса был задан явно (например, английский при русской
  системе), после «Сбросить настройки к значениям по умолчанию» язык в
  settings.json возвращался к «как в системе», но окно перезапуска не
  предлагалось — интерфейс продолжал работать на старом языке до ручного
  перезапуска (и наоборот). Теперь при сбросе программа сравнивает активный
  язык с тем, что получится после сброса, и при отличии сразу предлагает
  перезапуск.
- **Скрытый баг скачивания текстовых файлов** (`app/core/net.py`): запросы без
  явного `Accept-Encoding: identity` могли получать gzip-сжатый ответ, из-за
  чего проверка «размер против Content-Length» срабатывала ложно
  (сжатый заголовок против распакованного тела) и файл бесконечно
  «докачивался». Затрагивало восстановление файлов программы из GitHub
  (Диагностика) и любое скачивание текстовых файлов; теперь все загрузки
  идут через сессию с identity-кодированием.

### Изменено

- Версия приложения: 1.0.0 → **1.1.0** (`app/constants.py`).
- Манифест файлов программы в `launcher/bootstrap.py` пополнен новыми файлами
  (`app/core/updater.py`, `CHANGELOG.md`) — диагностика и восстановление
  файлов учитывают их.
- README: описаны автообновления и выбор формата результата в GUI.

## [v1.0.0] — 2026-10-25

Первый полноценный релиз.

- Локальное распознавание речи без облака: аудио и видео (~50 форматов)
  в текст, субтитры и JSON; видео автоматически конвертируется в звук.
- Шесть движков: faster-whisper (CTranslate2), whisper.cpp (GGML),
  Vosk (Kaldi), Qwen3-ASR и GigaAM (torch), hf-transformers (любая ASR-модель
  Hugging Face).
- Каталог из 19 моделей с фильтрами, поиском и сортировками; добавление своих
  моделей по ссылке/пути; докачка после обрыва сети с проверкой целостности.
- Качество текста: Silero VAD, анти-галлюцинации, абзацы, слова-подсказки,
  initial_prompt, перевод на английский, таймкоды.
- GUI на PySide6 (тёмная/светлая тема, двуязычный интерфейс ru/en), CLI
  (`transcribe`, `doctor`, `list-models`), журнал событий, диагностика и
  восстановление файлов программы.
- Портативный запуск на Windows: RUN.bat сам скачивает runtime Python
  и устанавливает зависимости строго внутри папки проекта; CUDA-ускорение
  torch-движков по предложению программы.
- Автоматические тесты (`tests/run_all.py`) и CI на GitHub Actions.
