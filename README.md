# 🎙️ LocalASR

Локальное распознавание речи (лекции, видео, подкасты) в текст, субтитры и JSON —
без облака и без отправки данных куда-либо. Интерфейс программы двуязычный
(русский / английский, по умолчанию — язык системы).

## ✨ Что умеет

- **Любые медиа**: mp4, mkv, mov, mp3, wav, flac, m4a, ogg и ещё ~40 форматов;
  видео автоматически превращается в звук.
- **Шесть движков**: faster-whisper (CTranslate2), whisper.cpp (GGML),
  Vosk (Kaldi), Qwen3-ASR и GigaAM (torch), универсальный hf-transformers
  (любая ASR-модель Hugging Face).
- **Каталог из 19 моделей** с размерами, потреблением памяти, языками и
  оценками точности/скорости; фильтры, поиск, сортировки; свои модели по
  ссылке или пути.
- **Качество текста**: Silero VAD, анти-галлюцинации, склейка в абзацы,
  слова-подсказки, initial_prompt, перевод в английский.
- **Результаты**: в окне программы — .txt (с таймкодами или без); через
  командную строку дополнительно .srt, .vtt, .json и .md (`-f …`,
  `--all-formats`). Имена файлов всегда уникальны (оригинал + дата и время).
- **Железо**: автоопределение CPU/GPU, CUDA-ускорение torch-моделей и
  faster-whisper (по предложению программы), батч-декодинг, параллельные файлы.
- **Устойчивость**: докачка моделей после обрыва сети, проверка целостности
  файлов программы, ремонт окружения, подробные логи по желанию.

## 🚀 Быстрый старт (Windows, portable)

Программа работает на портативном Python — системный не нужен: при первом
запуске **RUN.bat** сам скачает из интернета полную официальную сборку
Python 3.12 (~15 МБ, один раз).

1. Распакуйте/скопируйте папку проекта куда угодно.
2. Дважды кликните **RUN.bat** — при первом запуске скачается портативный
   Python и установятся зависимости (нужен интернет), затем откроется окно
   программы.
3. По желанию: дважды кликните **Create Shortcut.bat** — на рабочем столе
   появится ярлык **LocalASR** с иконкой; последующие запуски через него идут
   без мелькания консоли.

После переноса папки программы на другое место повторно запустите
**Create Shortcut.bat**, чтобы ярлык указывал на новый путь.

Требования: Windows 10/11 x64. Модели скачиваются внутри программы
(папка `models/`, от ~420 МБ до ~4.4 ГБ).

### Linux / macOS (режим разработчика)

Нужен Python 3.10–3.14 (64 бит):

```bash
python3 launcher/main.py   # создаст .venv, поставит зависимости, откроет GUI
```

На Debian/Ubuntu предварительно: `sudo apt install python3-venv`.

### Проверка без GUI

```bash
python launcher/run_app.py list-models        # каталог моделей
python launcher/run_app.py doctor             # диагностика окружения
python launcher/run_app.py transcribe "лекция 1.mp4" -m whisper-large-v3-turbo -f srt
```

## 🌐 Язык интерфейса

По умолчанию язык берётся из системы (Windows/POSIX-локали). Поменять можно в
любой момент: **Сервис → Настройки → Интерфейс → Язык интерфейса**
(«Определять автоматически», English, Русский). Смена применяется после
перезапуска — программа сама предложит перезапуститься. Каталог переводов:
`resources/i18n/ru.json`; полнота переводов контролируется тестом
`tests/test_i18n.py`.

## 🧠 Какую модель выбрать (рекомендация)

| Задача | Модель |
| --- | --- |
| Русские лекции, баланс точности и скорости | `ru-turbo-corriolon-int8` (~819 МБ) |
| Русский на слабом CPU | `gigaam-v3-e2e-rnnt` (449 МБ) или `gigaam-v3-e2e-ctc` (422 МБ) |
| Русско-английское смешение терминов | `ru-turbo-coriollon-codeswitch` |
| Любой язык, максимум точности | `qwen3-asr-1.7b` (нужен torch) |
| Английские доклады, максимум скорости | `distil-large-v3` |

Полные характеристики — в карточках моделей внутри программы.

## 🖥 Требования к железу

- CPU-распознавание: от 4 ГБ RAM (лёгкие модели) до 10+ ГБ (флагманы).
- NVIDIA GPU: CUDA-ускорение предлагается автоматически; нужны драйверы
  новее 525/527 и ~1 ГБ библиотек (cuBLAS/cuDNN 9).
- Свободное место: модель + двойной запас на время скачивания.

## ⚡ Почему это быстро

- Модель загружается один раз на всю очередь файлов.
- Звук декодируется в отдельном потоке с опережением (prefetch).
- faster-whisper считает в C++/CTranslate2 без GIL; batched-режим на GPU до 4×.
- torch-модели: батчи энкодера + многопоточный CPU-декод RNNT без
  синхронизаций GPU↔CPU на каждый токен.

## 🧪 Установка движков

Движки ставятся **по требованию**: когда вы запускаете модель, которой нужен
отсутствующий движок, программа показывает объём скачивания и спрашивает
подтверждение. Ручных действий не требуется. CUDA-библиотеки для
faster-whisper ставятся кнопкой в **Настройки → Движки**.

## 🧪 Тесты

```bash
cd <корень проекта>
python tests/run_all.py            # все тесты (каждый в своём процессе)
python tests/run_all.py --list     # список модулей
python tests/run_all.py i18n,net   # только выбранные
```

Модули, которым не хватает тяжёлых зависимостей (torch/transformers/PySide6),
помечаются SKIP — это нормально: базовые тесты требуют только numpy.
`tests/test_i18n.py` гарантирует, что все строки интерфейса присутствуют в
каталоге переводов (защита от рассинхрона).

## ⌨️ Командная строка (CLI)

```bash
python launcher/run_app.py transcribe "лекция 1.mp4" -m ru-turbo-corriolon-int8
python launcher/run_app.py transcribe ./лекции -f srt --words --timestamps --beam 8

python launcher/run_app.py transcribe интервью.mp3 --hotwords "Хаффман, RAG" --prompt "научный стиль"

python launcher/run_app.py version
```

## 🔧 Устранение проблем

- **Окно не открывается / мигает консоль** — смотрите `logs/bootstrap.log`
  (он остаётся только при ошибке запуска) и **Сервис → Открыть лог запуска**.
- **Нет звука в файле / нет аудиодорожки** — программа сообщит об этом в
  журнале и в таблице результатов.
- **Мало места** — карточка модели показывает размер; диагностика
  (**Сервис → Диагностика и восстановление**) найдёт лишние пакеты окружения.
- **Подробный лог для баг-репорта** — **Настройки → Журнал и диагностика →
  Вести подробный лог-файл**, затем повторите проблему и приложите свежий
  файл из `logs/`.
- **Пропали файлы программы** — диагностика восстановит их из репозитория
  одной кнопкой.

## 🤝 Вклад в проект

**Нашли ошибку?** Создайте Issue: опишите, что вы сделали и что пошло не так,
и приложите файл журнала из папки `logs/`. Чтобы журнал был подробным,
сначала включите **Настройки → Журнал и диагностика → Вести подробный
лог-файл**, затем повторите проблему.

**Хотите что-то исправить или добавить?** Сделайте форк репозитория, внесите
изменения и пришлите pull-request. Одно важное правило: новые строки интерфейса
добавляйте на английском через `_()`, а русский перевод — в
`resources/i18n/ru.json` (полноту проверяет тест `tests/test_i18n.py`).

Перед отправкой прогоните тесты: `python tests/run_all.py`.
